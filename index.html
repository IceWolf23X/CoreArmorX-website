Core feature set

A small armor system with the parts servers actually need.

CoreArmorX focuses on armor styling, reward distribution, safe conversion, and clean admin control instead of becoming a heavy custom-item framework.

Visual Armor Styles

Convert Netherite armor into Diamond, Gold, Iron, Chainmail, Leather, or future profile styles while keeping the functional value of the original equipment.

Metadata Preservation

Names, lore, enchantments, damage, repair cost, trims, flags, unbreakable state and custom data are preserved through conversion and reset flows.

Style Tokens

Physical token items make armor styles useful for crates, shops, ranks, events, quests, and rewards.

Config-Driven Recipes

Server owners decide which styles are enabled, which materials apply them, and which lore appears.

Vanilla+ positioning

Cosmetic freedom without changing the server's power curve.

Players get identity and style. Owners get a reward system. The armor still behaves like Netherite.

For players

Wear the look you want

Use styles without losing the value of a maxed Netherite set.

For owners

Turn styles into rewards

Tokens, commands, permissions, and future unlocks fit crate, shop, rank, and event workflows.

For admins

Inspect and reset safely

Commands expose CoreArmorX metadata and let staff restore styled items when needed.

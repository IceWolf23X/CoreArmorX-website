Setup

Install the jar, boot once, then test one style loop.

CoreArmorX is a Paper plugin. The MVP has no hard dependency on Vault, PlaceholderAPI, CoreCaseX, CoreChatX, ItemsAdder, Oraxen, or a resource pack.

Requirements

  • Paper 1.21.x, developed against Paper API 1.21.4.
  • Java 21.
  • Server restart access for first install.

Install

  1. Place CoreArmorX-1.0.0-SNAPSHOT.jar inside the server plugins folder.
  2. Restart the server.
  3. Confirm /plugins shows CoreArmorX.
  4. Open plugins/CoreArmorX/config.yml and adjust styles or recipe ingredients.
  5. Run /corearmorx reload after config edits.

First Test

  1. Give yourself Netherite armor.
  2. Craft it with a configured style ingredient using the default shape.
  3. Use /corearmorx inspect hand on the styled item.
  4. Use /corearmorx reset hand and confirm the item returns to visual Netherite.

Useful Commands

/corearmorx help
/corearmorx reload
/corearmorx apply diamond hand
/corearmorx apply gold armor
/corearmorx reset hand
/corearmorx inspect hand

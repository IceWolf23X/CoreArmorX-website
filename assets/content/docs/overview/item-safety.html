CoreArmorX preserves supported data while changing armor materials: custom name, original lore, enchantments, durability damage, max damage where supported, repair cost, trims, flags, unbreakable state, compatible custom data and non-CoreArmorX persistent data.

Foreign custom data

BLOCK_IF_DETECTED is the safe default: transformations stop when foreign persistent data is present. REPLACE_ANYWAY permits conversion and should be used only when the administrator knows the other item format is compatible.

CoreArmorX identity

Only skinned armor and its internal skin state carry CoreArmorX identity. Normal upgraded armor remains ordinary vanilla armor. This boundary avoids making every progression output dependent on the plugin.

Inspection and repair

/corearmorx inspect reports the held item’s current and clean materials, skin, model mode, lore snapshot and durability state. /corearmorx fixitem reapplies the configured profile and display to a recognized skinned item; it is not a generic item converter.

CoreArmorX is a Paper-only vanilla+ armor progression plugin for Minecraft/Paper 1.21.11 or newer and Java 21 or newer. It uses normal crafting and vanilla item behavior instead of custom menus, economies or databases.

Two item models

Normal upgraded armor uses its Bukkit material as the source of truth and receives no CoreArmorX persistent data. Skinned netherite armor stores its clean material, visual skin, original lore state, inventory model mode and optional cosmetic durability in Paper persistent data.

Standalone scope

CoreArmorX does not require Vault, PlaceholderAPI, a database, a GUI library, a resource pack, CoreToolsX or a custom-item plugin. A permissions plugin such as LuckPerms is useful only when progression locks are enabled.

Conservative defaults

  • Progression locks are disabled.
  • Skin durability is disabled.
  • Fire/lava skin stripping is disabled.
  • Foreign persistent data blocks transformations.
  • Protected direct recipes are replaced by the progression path.

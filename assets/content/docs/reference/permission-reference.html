Administration

  • corearmorx.admin — operator-default aggregate for reload, inspect, fixitem and progression bypass.
  • corearmorx.admin.reload, .inspect, .fixitem.
  • corearmorx.progression.bypass — bypasses progression checks.

Skins

corearmorx.skin.* aggregates .leather, .copper, .chainmail, .iron, .gold and .diamond.

Upgrades

corearmorx.upgrade.* aggregates .leather_to_copper, .copper_to_chainmail, .chainmail_to_iron, .iron_to_gold, .iron_to_diamond and .iron_helmet_to_turtle.

Usage locks

corearmorx.use.* aggregates leather, copper, chainmail, iron, gold, diamond, netherite and turtle tier nodes. Usage checks run only when progression locks and blocks.usage are enabled. Configured definition permission strings and usage prefix can be changed in YAML.

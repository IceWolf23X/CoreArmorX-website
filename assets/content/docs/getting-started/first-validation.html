Clean setup

  1. Confirm version 2026.1.2 enables on Paper 1.21.11+ with Java 21+.
  2. Run /corearmorx reload and review every warning.
  3. Craft one item through each enabled upgrade branch using separate one-item ingredient slots.
  4. Apply, inspect, fix and remove one netherite skin.
  5. Test leather dyeing and lore if leather skins are enabled.

Permission validation

If progression locks are enabled, test with a non-operator account. Verify upgrade, skin, usage and bypass behavior independently.

Safety validation

Test a foreign custom item before changing BLOCK_IF_DETECTED. If fire/lava stripping is changed, test both a dropped skinned item and the restored clean netherite result.

Production checklist

  • Keep a copy of the active YAML files.
  • Confirm the intended protected vanilla recipes are replaced.
  • Check recipe-book discovery separately from runtime crafting.
  • Do not assume a successful reload refreshes every existing item immediately.

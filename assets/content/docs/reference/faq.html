What does CoreArmorX require?

Paper/Minecraft 1.21.11+ and Java 21+. A permission plugin is optional unless locks are enabled.

Does it require Vault, PlaceholderAPI, a database or CoreToolsX?

No. It also needs no GUI library, custom-item plugin or resource pack.

Do normal upgrades receive plugin data?

No. Normal upgraded armor remains material-driven vanilla armor.

Can leather-skinned armor be dyed?

Yes. Vanilla dye behavior is retained and lore can expose the current color.

Can a skin have separate durability?

Yes, but the feature is disabled by default. Configure it globally, by skin or by armor piece.

Where is player progression stored?

Nowhere in CoreArmorX. Locks are permission-based.

What follows a normal YAML edit?

Run /corearmorx reload and review console warnings.

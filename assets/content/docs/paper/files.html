CoreArmorX generates four administrator-facing files in plugins/CoreArmorX/.

Runtime folder

The folder contains only the four YAML defaults below. It does not contain a public descriptor or player progression database.

config.yml

Global recipe behavior, ingredient groups, upgrade defaults, lore, leather color, inventory model, removal, fire/lava handling, progression locks and custom-item safety.

armor-upgrades.yml

Named progression routes with source/target tiers or exact materials, ingredients, costs and permissions.

armor-skins.yml

Named netherite skins, output materials and optional cosmetic durability.

messages.yml

MiniMessage text for commands, crafting, progression and item inspection.

Not public configuration

plugin.yml stays inside the JAR and is intentionally excluded from configuration sync, raw downloads and the documentation catalog.

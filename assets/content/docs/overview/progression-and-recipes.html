CoreArmorX routes protected direct armor crafting through configurable upgrade definitions. The bundled path is leather → copper → chainmail → iron → diamond, with iron → gold and iron helmet → turtle helmet as alternate endpoints.

Default routes

  • LEATHER → COPPER
  • COPPER → CHAINMAIL
  • CHAINMAIL → IRON
  • IRON → DIAMOND
  • IRON → GOLD
  • IRON_HELMET → TURTLE_HELMET

Recipe model

Ingredient groups accept configured Bukkit materials. Runtime matching requires separate one-item ingredient slots; stacking the cost into one slot is intentionally rejected. Static recipe-book recipes can expose discovery while the runtime matcher validates the real item, cost, metadata and permission.

Protected vanilla recipes

With recipes.override-vanilla-equipment-recipes: true, protected direct outputs use their matching minecraft:* keys. Leather armor crafting and vanilla diamond-to-netherite smithing are not changed. Original protected recipes return when the override is disabled or the plugin stops.

Costs and durability

VANILLA_RECIPE_COST uses 5/8/7/4 ingredients for helmet/chestplate/leggings/boots. CUSTOM reads a positive count. Upgrade output durability can be REFILL, KEEP_DAMAGE or KEEP_PERCENTAGE; repair cost preservation is separately configurable.

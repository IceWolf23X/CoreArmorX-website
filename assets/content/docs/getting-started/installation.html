Requirements

  • Paper/Minecraft 1.21.11 or newer.
  • Java 21 or newer.
  • The CoreArmorX JAR from Modrinth.

Download

Use the public Modrinth project for stable builds. The private plugin source repository is not a download or documentation endpoint.

Installation flow

  1. Stop the Paper server.
  2. Place CoreArmorX-2026.1.2.jar in plugins/.
  3. Start once and confirm the enable message has no configuration warnings.
  4. Edit files under plugins/CoreArmorX/.
  5. Run /corearmorx reload after normal YAML changes.

Generated files

plugins/CoreArmorX/
├── config.yml
├── armor-upgrades.yml
├── armor-skins.yml
└── messages.yml

plugin.yml is internal JAR metadata, not a server configuration file.

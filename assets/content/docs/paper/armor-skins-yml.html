This file defines netherite visual skins and the optional cosmetic durability layer.

Skin definition schema

skins.<id> supports enabled, display-name, ingredient, cost-mode, positive custom count, dyeable, permission, and output-materials.{helmet,chestplate,leggings,boots}. Defaults are leather, copper, chainmail, iron, gold and diamond.

Cosmetic durability schema

  • skin-durability.mode: DISABLED|GLOBAL|BY_SKIN|BY_ITEM.
  • global.max-durability.
  • by-skin.default-max-durability and by-skin.materials.<skin>.
  • by-item.default-max-durability and by-item.materials.<skin>.{default-max-durability,helmet,chestplate,leggings,boots}.
  • damage.mode (currently only MIRROR_REAL_DAMAGE) and damage.multiplier.
  • on-break (currently only REMOVE_SKIN).
  • mending.mode: DISABLED|SPLIT|DOUBLE.
  • placeholders.{disabled-value,bar-segments,bar-full,bar-empty}.

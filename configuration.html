Configuration

Control styles, recipes, tokens, lore, and permissions from YAML.

The MVP keeps configuration small enough to audit while still giving server owners useful control.

Files

  • plugins/CoreArmorX/config.yml
  • plugins/CoreArmorX/messages.yml

Settings

settings:
  debug: false
  preserve-custom-name: true
  add-style-lore: true
  require-permission-for-styles: false
  allow-full-set-apply: true
  allow-reset: true

Style Example

styles:
  diamond:
    enabled: true
    display-name: "<aqua>Diamond Style"
    rarity: RARE
    permission: "corearmorx.style.diamond"
    materials:
      helmet: DIAMOND_HELMET
      chestplate: DIAMOND_CHESTPLATE
      leggings: DIAMOND_LEGGINGS
      boots: DIAMOND_BOOTS

Recipe Ingredients

recipes:
  crafting:
    enabled: true
    ingredients:
      diamond: DIAMOND
      gold: GOLD_INGOT
      iron: IRON_INGOT
      chainmail: CHAIN
      leather: LEATHER

Tokens

Tokens are real items tagged with CoreArmorX PDC keys. They are intended for crates, shops, rank rewards, and event rewards. 

tokens:
  enabled: true
  consume-on-apply: true
  require-token-for-command-apply: false
  require-token-for-wardrobe-apply: true
  item-material: PAPER

Permissions

  • corearmorx.command
  • corearmorx.reload
  • corearmorx.apply
  • corearmorx.reset
  • corearmorx.inspect
  • corearmorx.token.give
  • corearmorx.style.<style>

Troubleshooting

  • If recipes do not change, run /corearmorx reload or restart.
  • If an item does not convert, confirm it is Netherite armor or a CoreArmorX styled item.
  • If a style is unavailable, confirm enabled: true and the material names are valid Bukkit materials.
  • If players cannot apply styles, check require-permission-for-styles and per-style permission nodes.

Safe with /corearmorx reload

The command reloads all four YAML files, rebuilds validated definitions, removes and re-registers CoreArmorX recipes, and normalizes the configured skin fire-resistance policy on online players’ items.

  • Runtime toggles and recipe-book behavior.
  • Upgrade and skin definitions.
  • Messages and permission strings stored in YAML.
  • Lore templates.
  • Inventory model and cosmetic durability for newly created or subsequently refreshed skinned items.

Restart required

  • Replacing the plugin JAR.
  • Changing Paper or Minecraft runtime.
  • Recovering from startup/classloading errors.
  • Performing a clean-boot validation after broad configuration edits.

Existing files are not merged

A reload does not add newly packaged keys to an existing YAML file. After an upgrade, compare the installed files with the synchronized defaults before relying on a new option.

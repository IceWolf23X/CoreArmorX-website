Plugin does not enable

Confirm Paper/Minecraft 1.21.11+, Java 21+, the correct JAR and complete startup logs. Restart after correcting classloading/runtime problems.

A recipe appears but will not craft

Use separate one-item ingredient slots. Check the route/skin is enabled, ingredient group is valid, permission locks, whether the base is already skinned and custom-item compatibility.

A direct vanilla recipe still works

Check recipes.override-vanilla-equipment-recipes, reload, and review warnings. Leather crafting and diamond-to-netherite smithing are intentionally untouched.

Reload does not change an existing item

Reload changes definitions for new/refreshed items. Use /corearmorx fixitem on a recognized skinned item when its display/profile needs refresh; restart only for the documented restart boundaries.

A custom item is blocked

The safe default rejects foreign PDC. Do not choose REPLACE_ANYWAY until compatibility is understood.

A dropped skin survives fire or lava

This is the default protection behavior. Enable skin stripping only if the intended result is clean netherite rather than destruction.

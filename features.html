Feature overview

Armor customization built around safe Netherite preservation.

CoreArmorX keeps the MVP focused: style armor, preserve data, expose useful admin commands, and keep future wardrobe, unlock, smithing, and CoreX integrations modular.

Material Styles

Default styles convert Netherite pieces into Diamond, Gold, Iron, Chainmail, or Leather visuals. Each piece maps by armor slot and can be enabled or disabled from config.

Netherite Behavior

Styled armor receives Netherite-equivalent armor points, toughness, knockback resistance, durability, and fire-resistant item behavior where supported by the Paper API.

PDC Identity

Styled armor and tokens use namespaced PersistentDataContainer keys instead of display text.

Conversion Loop

Players can apply a style, switch to another style, and reset back to visual Netherite.

Style Tokens

Admins can create physical style tokens for crates, shops, rank rewards, and events.

Command Surface

Apply, reset, inspect, reload, and token commands cover the MVP without forcing a GUI.

Roadmap-ready

The first release is small by design.

These systems are intentionally left modular so future phases can extend them without breaking the core conversion model.
